# FastNetwork - Sistema de Gestión de Clientes

## Descripción del Proyecto
Este proyecto consiste en el diseño e implementación de la base de datos relacional fast_network_db, desarrollada para la compañía FastNetwork. Su objetivo principal es registrar, controlar y administrar nuevos clientes de servicio de internet, garantizando la validez e integridad de los datos mediante el uso de restricciones SQL (Constraints).

## Estructura del Repositorio
* `README.md`: Documentación general del proyecto y su estructura.
* `schema.sql`: Script en SQL con los comandos DDL para la creación de la base de datos `fast_network_db`, sus tablas y la aplicación de las 6 restricciones de integridad.
