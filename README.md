# FastNetwork - Sistema de Gestión de Clientes

## Descripción del Proyecto
Este proyecto consiste en el diseño e implementación de la base de datos relacional fast_network_db, desarrollada para la compañía FastNetwork. Su objetivo principal es registrar, controlar y administrar nuevos clientes de servicio de internet, garantizando la validez e integridad de los datos mediante el uso de restricciones SQL (Constraints).

## Estructura del Repositorio

- `README.md`: Documentación general del proyecto y su estructura.
- `schema.sql`: Script en SQL con los comandos DDL para la creación de las tablas de la base de datos `fast_network_db` y la aplicación de las restricciones de integridad.

---

## Instrucciones de Ejecución
1. **Clonar o descargar este repositorio:**
   ```bash
   git clone https://github.com/ErickPadillaO/FastNetwork-.git
   cd FastNetwork-
   ```
2. **Abrir tu gestor de bases de datos preferido compatible con PostgreSQL (Beekeeper Studio, pgAdmin, DBeaver, etc.).**
**Crear la base de datos:**
   ```sql
   CREATE DATABASE fast_network_db;
   ```
3. **Cargar el esquema de tablas: Conéctate a la base de datos fast_network_db, abre el archivo schema.sql y ejecuta el script completo para crear las tablas y sus restricciones.**
